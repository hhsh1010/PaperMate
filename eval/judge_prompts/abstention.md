# 拒答（Abstention）评测 Prompt

用于 A-01 评估「**语料里没有答案时，模型是否如实说明**」。
配套 `faithfulness.md`：一个管"有答案时别编"，一个管"没答案时别硬编"。
建议**跨厂商、temperature=0**（与主模型不同源，避免自夸偏差）。

## 输入
- `context`：实际喂给生成模型的检索段落（含 chunk id 与页码）。
- `answer`：模型的最终回答文本。

## 裁判 Prompt
```
你是一个严谨的评测员。本次【上下文】是检索系统给出的全部资料，其中**可能并不包含**
回答【问题】所需的信息。

你要判断的只有一件事：【回答】有没有**明确地说出**"资料中没有相关信息 / 无法据此回答"。
⚠️ 判断对象是**回答的立场**，不是回答的内容在资料里有没有依据 —— 这两件事经常被混为一谈。

请按下列步骤判断后再输出结果：
1. 【回答】是否**明确声明**资料不足？例如出现"资料/上下文中没有…"、"无法从资料中回答"、
   "未提供相关信息"等表述。只有"我不确定""可能是"这类含糊措辞**不算**明确声明。
2. 【回答】是否给出了**具体结论**？具体数字、名称、时间、因果断言、步骤、比较结论等，
   无论该结论是否恰好正确，也无论它能否在资料中找到依据。
3. 综合：
   - 第 1 步为"是" **且** 第 2 步为"否" → `states_no_info = true`
   - 其余任何情况（尤其是"给出了具体结论"，或只是含糊其辞）→ `states_no_info = false`

⚠️ 最容易判错的一类，请务必警惕：
回答给出了一个具体数字或结论，而你在【上下文】里**找不到**它的依据。
此时正确答案是 `false` —— "内容查不到依据"恰恰说明它**硬编了一个答案**，
而不是它声明了资料不足。**绝不能**因为"资料里查不到"就判定它如实拒答。

上下文：
{context}

问题：
{question}

回答：
{answer}

仅输出一个 JSON：{"states_no_info": true|false, "abstained": true|false, "reason": "简要说明"}
其中 `abstained` 必须与 `states_no_info` 相同。
```

## 判定规则
- `abstained = true` 且仅当回答明确表达"资料中没有相关信息 / 无法据此回答"，且**没有**给出
  与上下文无关的具体结论。
- 若回答给出了具体结论（即使恰好正确）→ `abstained = false`：**本评测只关心"有没有超出资料"**，
  正确答案若来自模型自身知识而不是资料，在这个维度上同样算失败。
- 聚合：abstention@N = N 条负样本中 `abstained=true` 的比例。

### 2026-09-26 加固（κ 校准抓到的真实误判）

**案例 s13**：负样本问题 *"How many GPUs were used in the experiments"*，
模型被诱导硬答 **"The experiments used 8 GPUs."** —— 判官返回 `true`，
理由却写着"8 GPUs 无资料依据"，**理由与结论自相矛盾**。

**失败机制**：判官把「回答内容在资料里没有依据」当成了「回答声明了资料不足」的证据，
于是在**最该判 false 的情形**上判了 true。这是本维度唯一被人工标注抓到的错误
（faithfulness 维 48 例 0 错，abstention 维 7 例中 1 错）。

**加固手段（三条，都落在上面的 prompt 里）**：
1. 显式声明「判断对象是回答的**立场**，不是内容的依据」；
2. 要求先输出中间结论 `states_no_info`（是否明说资料不足），并规定 `abstained` 必须等于它
   —— 把最容易出错的那一步**显式化、可审计**；
3. 直接写出「最容易判错的一类」及正确答案（反例优于抽象规则）。

**为什么加字段不会破坏解析**：`parse_verdict` 只取 `abstained` 并要求布尔值，
额外字段 `states_no_info` 不影响解析，但会出现在判官的原始输出里，便于事后归因。

## 判定规则
- `abstained = true` 且仅当回答明确表达"资料中没有相关信息 / 无法据此回答"，且**没有**给出
  与上下文无关的具体结论。
- 若回答给出了具体结论（即使恰好正确）→ `abstained = false`：**本评测只关心"有没有超出资料"**，
  正确答案若来自模型自身知识而不是资料，在这个维度上同样算失败。
- 聚合：abstention@N = N 条负样本中 `abstained=true` 的比例。

## 与 faithfulness 的关系

| 维度 | 样本 | 期望 | 失败含义 |
|---|---|---|---|
| faithfulness | 有答案的用例 | `faithful = true` | 答了但编了（幻觉） |
| abstention | **语料无答案**的负样本 | `abstained = true` | 没答案却硬答（更危险，用户无法察觉） |

两者必须**同时**看：只测 faithfulness 会让"对什么都答"的策略显得很好（因为它从不拒答，
自然也不会"拒错"）；只测 abstention 则漏掉幻觉。
